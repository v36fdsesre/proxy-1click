Автообновление через GitHub

Как выпустить новую версию:
1. Поднимите version в manifest.json (например, 2.9.2 -> 2.9.3).
2. Загрузите ВСЕ изменённые файлы на GitHub за один раз (Add file -> Upload files -> Commit changes).
   Файл secrets.js не загружайте: в нём логины и пароли.
3. GitHub сам создаст релиз с тегом v2.9.3 и приложит архив proxy-extension.zip. Ничего вводить не нужно.
   Результат виден на вкладке Actions (зелёная галочка) и на странице Releases.
Если версия в manifest.json не выросла, нового релиза не будет.

Расширение раз в минуту смотрит последний релиз и обновляется само.
