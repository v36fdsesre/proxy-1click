Автообновление через GitHub

Что получится: расширение раз в 6 часов смотрит последний релиз вашего репозитория. Если версия новее,
на иконке появится «1», а в окне расширения кнопка «Скачать». Полностью тихо обновить расширение,
загруженное из папки, браузер не позволяет: после скачивания распакуйте архив поверх старой папки
и нажмите «Обновить» на странице расширений. Файл secrets.js при этом не пострадает, его нет в архиве.

Один раз настроить:
1. На github.com создайте ПУБЛИЧНЫЙ репозиторий (например, proxy-extension).
2. Загрузите в него все файлы из папки расширения, КРОМЕ secrets.js (он в .gitignore).
   В нём ваши логины и пароли, в публичный репозиторий его выкладывать нельзя.
3. В файле config.js впишите repo: "ваш-логин/proxy-extension".

Выпуск обновления:
1. Поднимите version в manifest.json (например, 2.5.0 -> 2.6.0) и загрузите изменения на GitHub.
2. Создайте на GitHub тег v2.6.0 (Releases -> Draft a new release -> Choose a tag -> Create new tag -> Publish).
   Версия тега должна совпадать с manifest.json.
3. GitHub сам соберёт архив proxy-extension.zip и приложит его к релизу.
