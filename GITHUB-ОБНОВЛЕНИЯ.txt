Автообновление через GitHub

Как выпустить новую версию:
1. Поднимите version в manifest.json (например, 3.1.0 -> 3.1.1).
2. Загрузите ВСЕ изменённые файлы на GitHub за один раз (Add file -> Upload files -> Commit changes).
   Файл secrets.js не загружайте: в нём логины и пароли.
3. GitHub сам создаст релиз с тегом v3.1.1 и приложит архив proxy-extension.zip.

Как версия попадает на компьютер: помощник Windows (kosmoproxy-helper.zip, ставится один раз)
раз в 5 минут проверяет последний релиз и заменяет файлы в папке расширения, кроме secrets.js.
Расширение само замечает новую версию manifest.json на диске и перезапускается.
Прямо из браузера записывать файлы в папку расширения нельзя: браузер не даёт менять файлы .js.
